Project Introduction

Project title: AI-Based CPW Microstrip Antenna Synthesis Using Simulation-Trained Neural Surrogates.

This graduation project addresses the design challenge of CPW-fed microstrip patch antennas operating between 1.0 and 7.0 GHz. Instead of running a full electromagnetic simulation for every design trial, we built a web platform that estimates return loss (S11), bandwidth, gain, efficiency, and VSWR from patch dimensions — and can suggest geometry when a target resonance frequency is specified.

Antenna structure — 12 shapes, 4 families

All designs share a consistent substrate and feed topology: FR-4-style substrate, coplanar waveguide (CPW) feed, and a radiating patch whose length (Lp) and width (Wp) are varied between 5 and 40 mm. The platform supports exactly 12 patch shapes, grouped into 4 families (three shapes per family), matching the CST Microwave Studio dataset:

  • Rectangular family: Rectangle, Stepped, T-Shape
  • Circular family: Ellipse, Semi-Circle, Pie-Sector
  • Triangular family: Isosceles Triangle, Inverted Trapezoid, Diamond
  • Polygonal family: Hexagon (Flat-top), Pentagon (House), Cross

Methodology

A large batch of CST simulations was used to build a structured dataset. A forward neural model learns the mapping from geometry to performance and full S11 curves. Predictions are anchored to the simulation database (exact match, interpolation, or nearest-neighbour blending) so results stay physically consistent. The inverse module searches patch dimensions within a shape family to match a user-defined target frequency, with optional priorities for gain or bandwidth.

Platform features

  • Forward simulation: enter Lp, Wp, and shape — view metrics, S11/VSWR plots, and a 2D geometry sketch.
  • Inverse design: choose one of the 4 families and a target frequency — obtain recommended Lp/Wp among that family's 3 shapes.
  • Validation tools: internal self-tests compare engine output against the CST dataset for quality assurance.
  • AETHER Assistant: conversational help for interpreting parameters and results (Groq LLM).

Scope and limitations

Results are valid within the trained geometry and frequency ranges of the dataset. The tool supports academic exploration, comparison, and demonstration — not a replacement for final sign-off simulation when fabricating hardware.

System Overview

Forward Prediction

Predicts resonance, bandwidth, and S11 from patch length, width, and any of the 12 shapes. Results are aligned with nearest CST simulation points in the dataset when available.

Inverse Design

Given a target frequency and one of four families (Rectangular, Circular, Triangular, Polygonal), searches Lp/Wp across that family's three shapes for the best match.

Engine Validation

Held-out CST fidelity

Leave-one-out fidelity check. Each sampled CST point is removed from the lookup table before the engine is asked to predict it, so the engine has to interpolate from neighbouring geometries. That is the quantity that matters: how well it predicts a design it has never seen. (The previous version sampled rows and then queried those same rows, so the engine returned the ground truth and every error read 0.000.)

CST interpolation vs. trained model

CST interpolation vs. the trained model

The app ships two predictors. The answers you see come from interpolating the CST dataset; the trained Keras surrogate is loaded but only used as a fallback (or when you tick Use ML refinement). Its training-time accuracy was measured on its own held-out split, which is not the same as measuring it here. This scores both paths against the same held-out geometries, so the choice of default is evidence-based rather than assumed.
