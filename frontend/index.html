About the project

AI-Based CPW Microstrip Antenna Synthesis is a Sulaymaniyah Polytechnic University graduation project for CPW-fed patch antennas operating from 1.0 to 7.0 GHz.

It uses CST simulation data and an existing trained surrogate to predict S11, bandwidth, gain, efficiency, and VSWR from a selected geometry—or to search for geometry from a target frequency.

The platform supports 12 shapes in 4 families. Forward dimensions are intentionally limited to the CST-backed 10–35 mm range. Use the results for academic exploration, then validate a fabrication candidate with a final electromagnetic simulation.

Engine Validation

Held-out CST fidelity

Leave-one-out fidelity check. Each sampled CST point is removed from the lookup table before the engine is asked to predict it, so the engine has to interpolate from neighbouring geometries. That is the quantity that matters: how well it predicts a design it has never seen. (The previous version sampled rows and then queried those same rows, so the engine returned the ground truth and every error read 0.000.)

CST interpolation vs. trained model

CST interpolation vs. the trained model

The app ships two predictors. The answers you see come from interpolating the CST dataset; the trained Keras surrogate is loaded but only used as a fallback (or when you tick Use ML refinement). Its training-time accuracy was measured on its own held-out split, which is not the same as measuring it here. This scores both paths against the same held-out geometries, so the choice of default is evidence-based rather than assumed.
