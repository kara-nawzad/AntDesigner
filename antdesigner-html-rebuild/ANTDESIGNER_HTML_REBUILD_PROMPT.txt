5.2  API (JSON; adjust names if you have a better scheme, keep the content)
   GET  /api/health      -> {status, engine_ready, v2_loaded, rows, versions}
   GET  /api/meta        -> shapes, families, priorities, slider range 5-40,

                            ML_BLEND_RADIUS_MM, TRAINED_* (so the UI never

   POST /api/forward     {shape_id, lp, wp, use_ml_refine}
        -> everything the Streamlit result dict has: status, engine, fr, bw,

           dist}, out_of_range (bool), neural_note: one of "active" |

        antenna_viz.antenna_animated_html; shown in a sandboxed iframe srcdoc)

        antenna_charts.s11_vswr_animated_html)
   POST /api/visual/3d       {shape_id, lp, wp} -> Plotly JSON

   POST /api/inverse     {target_fr, family, priority}
